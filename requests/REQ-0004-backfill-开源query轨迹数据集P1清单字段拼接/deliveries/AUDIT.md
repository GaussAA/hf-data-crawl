## 怎么核出来的

1. 逐条比 `manifest.json` 的 `method.env.commit` 与当时的提交顺序：
   - `6005ad0` 是「追加列」能力落地**之前**的提交，而 173045 / 173149 的产物含追加列，
     彼此矛盾 → 判不可复现；
   - `b4e0f28` 是 `--ids` 与布尔词表落地**之前**的提交，而 175159 的产物里 `实测行数`
     等列只可能由 `fetch-sizes --ids` 产生 → 判不可复现。
2. 逐字节比产物：`173149 == 173619`（sha `07488652…`）、`175159 == 175535`
   （sha `08a1eae6…`），两组各自相同 → 后一条是「重钉」而非新内容。
3. 逐格比 `173045` 与 `173149`：29 行 × 26 列**0 格不同**，差别只在列宽。
